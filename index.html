SAINT

A voice-first AI assistant for Windows. Say “Hey SAINT” and it listens, does the real thing, and answers out loud. The language model, wake word, speech recognition and voice all run on your own PC.

  • Does whole tasks. Plans multi-step requests, checks each step really happened, and tries another way when one fails.
  • Asks before it acts. Safe, Confirm and Autonomous modes, with anything that sends, deletes or closes waiting for your yes.
  • Your PC by voice. Apps, windows across monitors, browser, Spotify, reminders and memory, all stored locally.
  • SAINT Link. Your iPhone and other PCs talk to it, encrypted.

Game mod · Reverse engineering · Work in progress

By Arysr

Arkham Knight Split-Screen

Batman: Arkham Knight never shipped with split-screen. This mod adds up to four local players, and the hard part lives below the gameplay: the engine's renderer quietly assumes there is only ever one view.

  • Culling. The cull pipeline was hard-wired to view 0, so extra players saw nothing. It now runs once per view.
  • Lighting. The deferred lighting pass only lit the first view and smeared one stray normal across P2's reflections. Each pass is re-run per view.
  • SSBN. Screen-space bent normals were read and written at P1's pixels. Each view gets its own scratch pass.
  • Composite. An origin offset applied before checkerboard doubling wrote P2's image off the end of the buffer. One constant, re-staged.

Built in C# on BmSDK, with fixes traced shader by shader through the engine's D3D11 calls.
